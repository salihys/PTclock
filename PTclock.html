Offline Bluetooth page

Save this page to control the clock over Bluetooth without WiFi, using a browser that supports Web Bluetooth. Opening a saved file is browser/platform dependent. If necessary, use a trusted HTTPS host or localhost.

🔧 Maintenance mode (WiFi only)

The clock restarts into a small maintenance page for firmware updates and SD card files. The clock, alarms and azan pause until you restart it normally from that page. Use it if the normal update above fails.

🎥 Video mode

The clock restarts into a video player for the videos in /video on the SD card (made with convert_video.bat). Control it on the clock screen or from its own web page. It goes back to the clock by itself before the next azan or alarm.
